# CarDealTG

Telegram-бот для перепродажи авто: отслеживает объявления на киргизских
площадках по вашим запросам (поколение + цена — строго, остальное —
информационно).

## Запуск

### Первоначальная настройка (один раз)

1. Создайте бота у [@BotFather](https://t.me/BotFather), получите токен.
2. Узнайте свой telegram id (например, у @userinfobot).
3. Скопируйте `.env.example` в `.env`, впишите `BOT_TOKEN` и `OWNER_TELEGRAM_ID`.
4. Установите зависимости:

```
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
```

### Запуск бота — в одно действие

Дважды кликните **`run_bot.bat`** в папке проекта. Откроется окно консоли —
бот запущен, пока это окно открыто. Закрытие окна останавливает бота.

Если нужно запустить не мышкой, а из терминала: `run_bot.bat`
(или напрямую `.venv\Scripts\python -X utf8 main.py`).

⚠️ Не запускайте два окна бота одновременно — Telegram разрешает только
один активный процесс на бота и второй конфликтует с первым.

Автопроверка площадок — раз в 60 минут (меняется через /settings),
вручную — /check.

### Mac (в контейнере)

Двойной клик по **`mac-start.command`**. Нужен
[Docker Desktop](https://www.docker.com/products/docker-desktop/) —
версия для Apple Silicon. Скрипт сам скажет, если его нет или он не запущен.

При первом запуске он спросит `BOT_TOKEN`/`OWNER_TELEGRAM_ID` (откроет `.env`
на редактирование) и соберёт контейнер — пара минут, тянет Chromium для
Playwright. Дальше бот работает в фоне и переживает перезагрузку ноутбука.

| Файл | Что делает |
|---|---|
| `mac-start.command` | Запустить (и настроить при первом запуске) |
| `mac-stop.command` | Остановить |

База (`data/cardeal.db`), фото топ-3 и сохранённые сессии площадок лежат в
папке `data/` рядом со скриптами — пересборка контейнера их не трогает.

**Вход на площадки — прямо из Telegram:** 📤 Мои объявления → 🔐 Вход на
площадки. Бот поднимает в контейнере браузер на виртуальном экране и
открывает его в Telegram (noVNC через временный туннель cloudflared,
одноразовый пароль, закрывается сам через 15 минут). Телефон и код из SMS
можно написать боту сообщением — он впечатает их в поле под курсором.

Запасной вариант без Telegram — локально на Маке:
`python3 tools/login.py mashina` (нужны Python и `playwright install chromium`).

> Если файл не запускается двойным кликом, macOS мог снять права на
> исполнение при копировании: `chmod +x *.command`.

Посмотреть логи: `docker compose logs -f`. Обновить после изменений в коде:
`docker compose up -d --build`.

#### ИИ читает описания (Ollama на Маке)

Если на Маке стоит Ollama (`brew install ollama && brew services start ollama`,
модель — например `ollama pull llama3.1`), бот сам её найдёт и начнёт читать
описания объявлений. Настраивать ничего не нужно — модель выбирается из
установленных; статус видно в ⚙️ Настройки.

Что делает:
- в топ-3, среднюю цену и /pricecheck не пускает машины, у которых в описании
  «битая», «на запчасти», «не на ходу», цена за первый взнос / рассрочку /
  аренду, учёт или нахождение не в КР;
- находки по запросам с такими пометками не присылает, остальным добавляет
  строку «🤖 Из описания: …».

Необязательные настройки — в `.env` (см. `.env.example`): `AI_MODEL`,
`AI_ENABLED=false`, другой сервер через `AI_BASE_URL`.

#### Автообновление с GitHub

Если папка на Маке получена через `git clone` (не распакована из `.zip`),
можно включить автообновление — раз в 5 минут Мак сам сверяется с GitHub
и, если код изменился, подтягивает его и пересобирает контейнер:

```bash
./mac-autopull-install.command
```

| Файл | Что делает |
|---|---|
| `mac-autopull-install.command` | Включить автообновление |
| `mac-autopull-uninstall.command` | Выключить |

Лог проверок — `autopull.log` в папке проекта. Работает только на
git-клоне с настроенным `origin` — на копии из zip тянуть неоткуда.

**Обновить сразу, не дожидаясь 5 минут:** кнопка «🔄 Обновить с GitHub» в
главном меню бота (видна только владельцу). Бот кладёт `data/update_request.json`,
launchd на Маке сразу запускает автообновление, итог приходит в чат.
После обновления скриптов автообновления перезапусти
`mac-autopull-install.command` один раз, чтобы launchd подхватил изменения.

Папка бота **не должна лежать в «Документах», на «Рабочем столе» или в
«Загрузках»** — macOS не пускает туда фоновые задачи, и в логе будет
`Operation not permitted`. Клонируй в домашнюю папку: `cd ~ && git clone …`.

## Команды

- `/add_search` — добавить поисковый запрос (мастер)
- `/add_sold` — записать проданное авто; автоматически создаёт поиск похожих
  по цене продажи ± допуск
- `/pricecheck` — разовая проверка цены по модели (не создаёт запрос):
  самые дешёвые актуальные варианты + средняя цена. Можно сузить по годам и
  задать теги, которые ИИ ищет в описаниях: «корея, limited»; «страна: корея,
  комплектация: limited» — если из описания не ясно, бот сам пишет продавцу в
  чат lalafo (с аккаунта владельца, только в его поисках; не больше 10 за
  поиск и 30 в сутки, одному объявлению — один раз) и присылает разобранный
  ИИ ответ. Неясные объявления показываются отдельно и в среднюю цену не входят
- `/my_requests` — список запросов (пауза / изменить / удалить / найденное)
- `/check` — проверить площадки сейчас
- `/archive` — поиск по архиву всех спаршенных объявлений
- `/find <слово>` — поиск по слову во всём архиве
- `/add_keyword`, `/keywords` — слежение за ключевыми словами
- `/settings`, `/set_interval N`, `/set_tolerance N`, `/set_scan_interval N` — настройки

Владельцу бота дополнительно доступны команды постинга/поднятия
объявлений (`/post`, `/my_ads`, `/adopt`, `/login`) — скрыты от остальных.
